⚡ Blockworld
Built by the Vibe Coding Club

Step into a block world.

A procedurally generated 3D island you can walk around, climb, and reshape — entirely in your browser, no install, no login. Break blocks, place blocks, go explore.

🗺️

A new island every load

Terrain, hills, beaches and trees are generated with layered noise — refresh for a different world.

🧱

Break & place blocks

Seven block types on the hotbar. Dig into hills, build a tower, terraform the coastline.

🕹️

First-person exploring

Mouse look, WASD movement, jumping — the controls you already know from every block game.

⚙️

Built on Three.js

A real WebGL renderer, a hand-rolled voxel mesher, and Perlin noise terrain — all readable club code.

🚫

No install, no account

It's a webpage. Send the link, it loads, you're exploring in seconds.

🔓

Open source

The whole engine is one readable file — a great first look at how 3D on the web works.

Made by students, for students

This app is a project from our school's Vibe Coding Club — a group that builds real things together, learns by shipping, and welcomes anyone curious about code, no experience required.
